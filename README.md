👕 Online Clothing Store

An online shopping platform where users can explore clothing collections, browse different categories, and shop for their favorite fashion items.

✨ Features
- Browse clothing collections
- Explore different categories
- View product details and prices
- Add products to cart
- User-friendly interface

🛠️ Technologies
- HTML
- CSS
- JavaScript

🎯 Purpose
Developed to practice web development and create a simple, convenient online clothing shopping experience.
